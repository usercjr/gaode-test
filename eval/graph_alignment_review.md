# 知识图谱实体对齐：人工抽检

对齐：笔记元数据中的地点名 → 高德 POI（`agent_service/graph/align.py`），870 个（地名, 城市）中 669 个找到候选。
抽检人：开发者本人（单人判断，存在主观性）。

## 第一轮（规则 v1，随机种子 11，30 条）

正确 21 / 30（70%）。错误 9 条分两类：

| 类型 | 条数 | 例子 |
|---|---|---|
| 高德名称是查询的短片段（只匹配到泛称） | 5 | 中博商业步行街 → 商业步行街；都匀东黄记地摊火锅 → 地摊火锅；不正屋顶咖啡 → 屋顶咖啡（另一家店）；大瀑布水帘洞 → 瀑布；慢慢商店 → 慢慢 |
| 查询被包含在更长的商户名里（借名的店） | 4 | 蓝月谷 → 安宁蓝月谷温泉酒店；洱海 → 大理白族洱海渔庄店（昆明）；水立方 → 水立方拍照留念点（专卖店）；陶艺 → 迷上泥吧·陶艺坊 |

据此在建图阶段（`graph/build.py:accept`）新增两条规则：
1. 高德名称比查询短 2 个字及以上 → 拒绝
2. 高德名称比查询长 3 个字及以上、且为住宿 / 餐饮 / 购物 / 生活服务 / 体育休闲类 → 拒绝

采用的对齐由 669 降为 479（也误伤了少量正确项，如“新疆炒米粉-和平南街店”“金陵东路渡口”）。

## 第二轮（规则 v2，换随机种子 23，重新抽 30 条，未据此再调规则）

| 判断 | 条数 | 说明 |
|---|---|---|
| 正确 | 25 | |
| 错误 | 3 | 肠旺面 → 老七肠旺面（菜名被当成店名）；脆哨 → 李家脆哨（同上）；珍宝馆（故宫珍宝馆）→ 缅甸珍宝馆（珠宝店） |

精确率约 83%~90%（不确定项分别按错 / 对计）。剩余主要错误类型是“菜名被匹配到以该菜命名的店”，需要在元数据抽取阶段区分“菜品”与“地点”才能根治，列为后续工作。

## 其他规则处理

- 名称不完全一致且为学校、医院、公司、住宅等类别 → 拒绝（52 条，如“黑芝麻胡同” → “黑芝麻胡同小学”）
- 只写了品牌名的连锁店（如“紫光园” → “紫光园(隆福寺店)”）标记为“分店是猜的”，不参与 NEAR（附近）边
- 高德返回无 poi_id 的条目 → 拒绝（9 条）

## 第三轮（规则 v3，随机种子 37，30 条）

v2 之后在真实查询上发现地标被误删：“春熙路 → 春熙路步行街”“洪崖洞 → 洪崖洞夜市街区”被规则 2 当成借名商户拒绝，
导致图谱里没有这两个地标。逐条查看规则 2 拒绝的 80 条后，绝大多数确实应拒（“那拉提 → 新疆那拉提羊肉串”“宝塔山 → 宝塔山油漆总经销”），
误删的都是街区 / 步行街 / 美食街 / 市场，因此只对这类名称豁免规则 2（v3）。采用的对齐 479 → 490。

| 判断 | 条数 | 说明 |
|---|---|---|
| 正确 | 24 | |
| 错误 | 4 | 白宫 → 白宫旅拍（摄影店）；布达拉宫展 → 深圳的“布达拉宫”；瓦猫（工艺品）→ 神奇瓦猫（专卖店）；春熙路（成都）→ 深圳的同名道路 |
| 不确定 | 2 | 公共文化中心（泛称）；周官屯村 → 村内的木雕坊 |

精确率约 80%~87%。第二、三轮合计 60 条：正确 49，错误 7，不确定 4，约 **82%~88%**。

剩余错误的来源已不在对齐规则，而在更早的元数据抽取：
1. 把菜品、工艺品、展览当成地点（肠旺面、脆哨、瓦猫、布达拉宫展）
2. 多城市笔记里地点被归到错误城市（春熙路 → 深圳、朝天宫 → 厦门）

需要在抽取阶段区分“地点 / 菜品 / 商品”并逐个地点标注城市，列为后续工作；对齐规则不再继续调整，避免对抽检样本过拟合。
