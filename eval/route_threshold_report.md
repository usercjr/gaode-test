# 路由置信度阈值

- 运行日期：2026-10-13
- 规则：本地路由模型最高概率 < 阈值时交给 LLM 零样本判断
- 阈值只在 dev 集（40 条人工消息）上选择；held-out 集（40 条，选阈值前编写并提交，见 git 历史）只报告一次
- 选择标准：准确率最高；并列时“想改行程却没改”的条数更少者优先，再看本地处理占比
