# 知识图谱实体对齐：人工抽检

对齐：笔记元数据中的地点名 → 高德 POI（`agent_service/graph/align.py`），870 个（地名, 城市）中 669 个找到候选。
抽检人：开发者本人（单人判断，存在主观性）。

## 第一轮（规则 v1，随机种子 11，30 条）

正确 21 / 30（70%）。错误 9 条分两类：

| 类型 | 条数 | 例子 |
|---|---|---|
| 高德名称是查询的短片段（只匹配到泛称） | 5 | 中博商业步行街 → 商业步行街；都匀东黄记地摊火锅 → 地摊火锅；不正屋顶咖啡 → 屋顶咖啡（另一家店）；大瀑布水帘洞 → 瀑布；慢慢商店 → 慢慢 |
| 查询被包含在更长的商户名里（借名的店） | 4 | 蓝月谷 → 安宁蓝月谷温泉酒店；洱海 → 大理白族洱海渔庄店（昆明）；水立方 → 水立方拍照留念点（专卖店）；陶艺 → 迷上泥吧·陶艺坊 |

据此在建图阶段（`graph/build.py:accept`）新增两条规则：
1. 高德名称比查询短 2 个字及以上 → 拒绝
2. 高德名称比查询长 3 个字及以上、且为住宿 / 餐饮 / 购物 / 生活服务 / 体育休闲类 → 拒绝

采用的对齐由 669 降为 479（也误伤了少量正确项，如“新疆炒米粉-和平南街店”“金陵东路渡口”）。

## 其他规则处理

- 名称不完全一致且为学校、医院、公司、住宅等类别 → 拒绝（52 条，如“黑芝麻胡同” → “黑芝麻胡同小学”）
- 只写了品牌名的连锁店（如“紫光园” → “紫光园(隆福寺店)”）标记为“分店是猜的”，不参与 NEAR（附近）边
- 高德返回无 poi_id 的条目 → 拒绝（9 条）
