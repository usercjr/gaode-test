# RAG 检索评测报告

- 运行日期：2026-10-12
- 语料：`data/travel_notes.csv`，217 篇笔记 / 382 个 chunk
- 评测集：186 条查询（基于笔记生成 136 条，开放式 50 条），其中 152 条存在高度相关笔记，参与 Recall/MRR 统计
- 相关性标注：4 种检索方式各取前 10 篇 + 来源笔记组成候选池（平均 17.7 篇/查询），由 `deepseek-chat` 按 0/1/2 判分；人工核验 0 条（抽检表 `eval/data/rag_review.csv`）
- Embedding：`BAAI/bge-small-zh-v1.5`；Reranker：`BAAI/bge-reranker-base`（重排前 20 条，max_length=256，CPU）

## 结果（笔记级）

| 配置 | Recall@5 | MRR@10 | nDCG@5 | P@5(≥1) | nDCG@5 基于笔记 / 开放式 | 延迟 P50 / P95 |
|---|---|---|---|---|---|---|
| 向量 | 0.845 | 0.846 | 0.775 | 0.681 | 0.813 / 0.671 | 13 / 17 ms |
| BM25 | 0.765 | 0.760 | 0.658 | 0.556 | 0.735 / 0.448 | 3 / 4 ms |
| 混合（RRF） | 0.848 | 0.869 | 0.793 | 0.701 | 0.844 / 0.655 | 15 / 18 ms |
| 向量 + 地名过滤 | 0.845 | 0.848 | 0.801 | 0.720 | 0.830 / 0.722 | 26 / 29 ms |
| 混合 + 地名过滤 | 0.854 | 0.879 | 0.826 | 0.747 | 0.863 / 0.726 | 31 / 36 ms |
| 混合 + 地名过滤 + bge-reranker | 0.896 | 0.922 | 0.859 | 0.768 | 0.901 / 0.744 | 3196 / 3717 ms |
| 混合 + 地名过滤 + bge-reranker + LLM 改写 | 0.895 | 0.930 | 0.847 | 0.751 | 0.899 / 0.704 | 2968 / 3221 ms |

## 结论

- nDCG@5 最高的配置：**混合 + 地名过滤 + bge-reranker**（0.859，向量基线 0.775，相对提升 +10.8%）。
- Recall@5：向量基线 0.845 → 最佳 0.896。
- 延迟为单机 CPU 检索耗时（不含 LLM 回答生成）；带 LLM 改写的配置不含改写本身的耗时（约 1~2 秒）。

## 方法局限

- 判分由 LLM 完成，尚未全部人工核验；建议抽检 `rag_review.csv` 后在报告中注明一致率。
- 候选池只来自部分检索方式，池外笔记一律按不相关计；`判分覆盖率` 列见下表，越接近 1 越可靠。
- 73% 的查询由某篇笔记生成，词面上可能偏向该笔记，对 BM25 略有利；表中单列了两类查询的 nDCG@5。
- 判分覆盖率低于 1 的配置（如带 LLM 改写的配置）会召回候选池外的笔记，这些笔记按不相关计，分数偏保守。
- 语料只有 217 篇，结论的统计显著性有限；扩充语料后需要重跑。
