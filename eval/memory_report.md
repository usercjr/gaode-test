## 说明

- 用例与期望由开发者编写，规模小，只说明趋势。
- m12 多记的“不喜欢一天赶多个景点”可视为对原话的正确理解，是期望标签写得偏严；为避免事后调整，未修改标签。
- m10（先说喜欢博物馆、后改口不喜欢）在第一版中两条记忆同时生效：LLM 把动词写进了 value，改口规则按字面比较没匹配上。修复为比较去掉“喜欢/不喜欢/逛”等词后的对象，并在提示词中要求 value 只写对象。
- B 中除 s1 外由 LLM 判分，可能与人工判断不一致；每个场景只跑一次。
