- 带图谱：熊猫基地在成华区北三环外，市区景点基本都在南边，所以“顺路”主要是回城方向。按游记共现和实际距离，推荐这几个：  1. **文殊院** — 约13.2km，公交/地铁约80分钟，评分4.8。1篇游记提到。回城路上最顺的一个，地铁1号线可达，周边小吃多。 2. **春熙路步行街** — 约14.9km，约83分钟，评分4.9。2篇游记提到（14篇提及）。地铁3号线直达，逛街吃饭方便。 3. **人民公园** — 约17.3km，约92分钟，评分4.8。2篇游记提到。适合下午喝茶歇脚。 4. **宽窄巷子景区** — 约17.5km，约93分钟，评分4.8。2篇游记提到。和人民公园挨着，可连着逛。

**去完沙面还能去哪逛**

- 不带图谱：从沙面出发，顺路的几个选择：  1. **上下九商业步行街**（荔湾区）— 步行约 1.1 km / 15 分钟，评分 4.7。老字号小吃和骑楼街，最顺路。 2. **永庆坊**（恩宁路99号）— 步行约 1.5 km / 21 分钟，评分 4.8。西关骑楼改造的文创街区，和上下九可连成一条线。 3. **沙面公园** — 就在岛上，步行约 240 m，评分 4.7。想轻松点可以先在岛上江边坐坐。 4. **北京路步行街** — 公交/地铁约 38 分钟（4.75 km），评分 4.8。想换到市中心逛可考虑。 5. **广州塔** — 地铁约 47 分钟（11.5 km），评分 4.8。适合傍

## 说明

- “游记里提到过的地点”按图谱中被至少一篇游记提到的 POI 名称在回答中的出现计数；带图谱的回答天然更容易命中，这个指标衡量的是“推荐是否有真实旅行者依据”，不是正确性。
- 盲评由 LLM 完成，可能与人工判断不一致；问题由开发者编写，规模小（16 条）。
