## 说明

- 吞吐和延迟受本机 CPU 影响，换机器数值会变；这里关注的是**随并发变化的趋势**和**保护机制是否按设计生效**。
- 聊天吞吐的上限由 LLM 并发闸门决定（约 并发上限 ÷ 单次 LLM 耗时），真实环境下还受 DeepSeek 自身限流影响。
- 检索是 CPU 密集计算，在线程池中执行；单进程下并发提高后吞吐有限，扩容需要多进程 / 多实例。
